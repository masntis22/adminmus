# Admin Channel Bot

ربات تلگرام ادمین مدیریت کانال

## امکانات

- 📤 **ارسال پیام به کانال** - ارسال پیام کانفیگ شده با عکس و موزیک
- ⏰ **زمان‌بندی ارسال** - ارسال خودکار در ساعات مشخص
- 🎵 **ویرایش موزیک** - تغییر عنوان، هنرمند و کاور آرت
- ⚙️ **تنظیمات پیام‌ها** - ساخت، ویرایش و حذف پیام‌ها

## نصب

```bash
pip install -r requirements.txt
```

## اجرا

```bash
export BOT_TOKEN="توکن_ربات"
export ADMIN_IDS="123456789"
python3 bot.py
```

## راهنما

1. ربات رو با `/start` شروع کنید
2. نام کانال رو وارد کنید
3. آیدی ادمین‌ها رو وارد کنید
4. از منوی اصلی استفاده کنید
